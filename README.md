CleanTalk Anti-Spam extension for phpBB 3.3.x
============================================

If you find this project useful, please consider starring ⭐ it on GitHub — it helps us grow and support development!

## How to install.
  * Follow standard instruction at https://www.phpbb.com/extensions/installing/
    - copy 'cleantalk' folder with all subfolders int your 'ext' directory.
    - enable 'CleanTalk. Spam protection' extension.
  * Get access key at https://cleantalk.org/register?platform=phpbb3
  * Go to this extension settings page and save access key and needed antispam options.
  * Inform your users and enable "Users are informed" on the settings page. Spam protection stays paused until this option is enabled.

## About extension in short.
  * Stops spam bots signups.
  * Stops spam bots posts.
  * Allow guests posting without CAPTCHA.

## Privacy.
To check submissions for spam, the extension sends the e-mail address, IP address, browser user agent, username and message text of the submitter, as well as the page address and referrer, to CleanTalk servers. SpamFireWall sends the IP address, user agent and visited addresses of blocked visitors.
When "Users are informed" is enabled, the extension adds a "Spam protection by CleanTalk" section to the board's Privacy Policy (`ucp.php?mode=privacy`).
CleanTalk Privacy Policy: https://cleantalk.org/privacy

## Requirements.
  * phpBB 3.3.0+
  * PHP 7.2+
  * CleanTalk account https://cleantalk.org/register?product=anti-spam
